# Screenshots

This directory is reserved for genuine visual captures of the n8n workflow canvas, node execution outputs, and sample published posts.

> **Policy:** No fabricated or placeholder screenshots are included in this repository. Add real screenshots captured from your own n8n instance after running the workflow.

## Recommended Captures

1. `workflow-canvas.png` — Full 14-node n8n canvas showing the three node groups (*Plan post topic*, *Create post assets*, *Publish and alert me*).
2. `execution-merge-output.png` — Execution view of the `Merge` node combining the Gemini binary image and `Hashtags` JSON.
3. `telegram-alert.png` — Mobile or desktop screenshot of the formatted `Notify on Telegram` confirmation message.
